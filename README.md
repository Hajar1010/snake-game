# Snake Game 

A lightweight, modern, responsive retro Snake Game built entirely with vanilla web technologies. It dynamically adapts to your device and features a dark neon theme, fluid collision detection, adaptive grid scaling, and smooth mechanical speed scaling.

## Features
* **Cross-Platform Adaptation:** Automatically configures itself for both mobile touchscreens and desktop laptop interfaces.
* **Modern Arcade Aesthetic:** Dark-mode styling paired with radiant neon indicators for both the snake and the target payload.
* **Progressive Difficulty Curve:** Increases game speed linearly by 50ms intervals per point scored, locked to a performance safety floor of 100ms.
* **Free Hosting Deployment:** Optimized config ready for direct deployment via GitHub Pages.

## Technologies Used
* **HTML5:** Structuring layout nodes.
* **CSS3 Flexbox/Grid:** Interface layout formatting and pulsing aesthetic animations.
* **JavaScript (ES6+):** Core game mechanics, directional matrices, dynamic tile distribution, and state lifecycle loops.

## How to Play
   https://hajar1010.github.io/snake-game/

### On Laptop / Desktop
1. Click the **Start/Restart** button.
2. Use your keyboard's **Arrow Keys** (`Up`, `Down`, `Left`, `Right`) to steer the snake.

### On Mobile / Tablet
1. Tap the **Start/Restart** button.
2. **Swipe your finger** anywhere on the screen in the direction you want the snake to turn (`Swipe Up`, `Swipe Down`, `Swipe Left`, `Swipe Right`).

### Game Rules
* Eat the pulsing red apples to increase your score and snake length.
* Avoid running into the perimeter borders or colliding with your own body tail tiles, or it will result in an immediate **Game Over**.
