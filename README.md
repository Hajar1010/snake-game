# Snake Game 

A lightweight, modern, responsive retro Snake Game built entirely with vanilla web technologies. It features a dark neon theme, fluid collision detection, adaptive grid scaling, and smooth mechanical speed scaling.

## Features
* **Dynamic Grid Layout:** Automatically generates grid tiles with JavaScript, keeping the HTML template pristine.
* **Modern Arcade Aesthetic:** Dark-mode styling paired with radiant neon indicators for both the snake and the target payload.
* **Progressive Difficulty Curve:** Increases game speed linearly by 50ms intervals per point scored, locked to a performance safety floor of 100ms.
* **Free Hosting Deployment:** Optimized config ready for direct deployment via GitHub Pages.

## Technologies Used
* **HTML5:** Structuring layout nodes.
* **CSS3 Flexbox/Grid:** Interface layout formatting and pulsing aesthetic animations.
* **JavaScript (ES6+):** Core game mechanics, directional matrices, dynamic tile distribution, and state lifecycle loops.

## How to Play
   https://hajar1010.github.io/snake-game/
1. Click the **Start/Restart** button to launch or clear the session state.
2. Use your keyboard's **Arrow Keys** (`Up`, `Down`, `Left`, `Right`) to control the direction of the snake.
3. Eat the pulsing red apples to increase your score and length.
4. Avoid running into the perimeter borders or colliding with your own body tail tiles, which will result in an immediate Game Over.
